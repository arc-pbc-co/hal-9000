Demo-ready path

Run the HAL-9000 research demo.

This runbook gives any ARC teammate a repeatable path for presenting HAL-9000: start from seeded data for reliability, then optionally run a live custom research topic when network/API conditions are safe.

What The Demo Proves

One research ledger, multiple surfaces.

Shared memory

HAL stores documents, chunks, claims, outputs, graph edges, and review decisions in one durable research ledger.

Agent control

Sessions can stream events, request approvals, compact context, replay history, and route tools through HAL policy.

Reviewable output

Briefs, evidence tables, graph context, ADAM exports, and audit manifests stay source-backed and inspectable.

1. Prepare The Workspace

Use a clean local database.

This keeps rehearsals isolated from any existing local HAL data. Run from the HAL repo root.

cd /path/to/hal-9000

export HAL9000_DEMO_ROOT="${PWD}/.hal9000_demo"
mkdir -p "$HAL9000_DEMO_ROOT"

export HAL9000_DATABASE__URL="sqlite:///${HAL9000_DEMO_ROOT}/hal-demo.db"
export HAL9000_STORAGE__ROOT_PATH="${HAL9000_DEMO_ROOT}/objects"
export HAL9000_ACQUISITION__UNPAYWALL_EMAIL="demo@arc-pbc.com"

python3 -m alembic upgrade head
2. Seed The Reliable Demo

Create a project with reviewable data.

This path does not depend on live paper downloads or model/provider availability, so it is the recommended meeting-room demo.

python3 -m hal9000.cli research demo-seed \
  --project-slug hal-demo \
  --project-name "HAL-9000 Demo" \
  --owner demo@arc-pbc.com \
  --reviewer demo@arc-pbc.com \
  --contributor demo@arc-pbc.com
3. Start The Presentation Surfaces

Run the cockpit and deck locally.

Use two terminals. Keep both running during the demo.

Terminal A: HAL app gateway

lsof -nP -iTCP:9101 -sTCP:LISTEN

python3 -m hal9000.cli gateway http --host 127.0.0.1 --port 9101

If lsof already shows a Python/HAL process on 9101, the cockpit is already running; open http://127.0.0.1:9101/ui and continue. To restart cleanly, stop that process with kill <PID>, or use --port 9104 and open http://127.0.0.1:9104/ui.

Terminal B: static artifact server

python3 -m http.server 9102 --bind 127.0.0.1 --directory "$PWD"

Open these URLs

http://127.0.0.1:9102/artifacts/presentations/hal-9000-general-demo.html
http://127.0.0.1:9101/ui
4. Presenter Flow

Show the loop, not just the chat.

  1. Open the deck and frame HAL as ARC's research operating system: source-backed memory, governed agent runtime, reviewable outputs.
  2. Open the cockpit. Set User email to demo@arc-pbc.com and Project slug to hal-demo.
  3. Click Create Session, then show the chat/event feed and model picker.
  4. Open Review, click Load Review, select a run, and show the staged outputs.
  5. Open Evidence with the selected run id and show claims/chunks/output counts.
  6. Open Graph and show the relationship view: documents, claims, outputs, and review context.
5. Optional Custom Topic

Run a live research topic when conditions allow.

Use this only when internet access and acquisition dependencies are available. For customer meetings, run this before the call and present the resulting run.

python3 -m hal9000.cli research init-program \
  research/programs/custom-demo-topic.md \
  --name "Custom HAL Demo Research Program" \
  --objective "Research a focused technical topic selected for this audience, preserving source-backed claims, evidence tables, open questions, and ADAM-ready context." \
  --owner demo@arc-pbc.com \
  --domain materials_science

python3 -m hal9000.cli research save-program \
  research/programs/custom-demo-topic.md \
  --project-slug hal-demo

python3 -m hal9000.cli research queue-run \
  --project-slug hal-demo \
  --program-id <PROGRAM_ID> \
  --initiated-by demo@arc-pbc.com

python3 -m hal9000.cli research execute-run <RUN_ID> \
  --actor demo-worker \
  --live-acquisition \
  --max-attempts 2 \
  --phase-timeout-seconds 300

Troubleshooting

Fast fixes during rehearsal.

  • Old styling: hard refresh the browser tab.
  • Port already in use: the gateway is already running, or another process owns 9101. Run lsof -nP -iTCP:9101 -sTCP:LISTEN, open the existing cockpit, stop it with kill <PID>, or start HAL with --port 9104.
  • Empty review queue: re-run demo-seed with the same hal-demo project slug.
  • Live acquisition fails: continue with seeded data; live acquisition is optional for the demo.
  • Reset everything: stop servers and remove .hal9000_demo, then rerun the setup.
