Flight Plan

HAL-9000 is being rebuilt as a shared, auditable research operating system. The agent layer is a graft: it gives HAL durable execution mechanics without replacing HAL's research memory, provenance, or review model.

HAL-9000

A research OS for source-backed scientific work.

HAL connects acquisition, PDF processing, semantic memory, graph relationships, agent execution, review, collaboration, and exports around one durable ledger.

Opening line: HAL is not a chatbot wrapper. It is a platform pattern for keeping scientific work inspectable after the model finishes talking.

Observe Acquire papers, parse PDFs, normalize metadata, and retain source records.
Reason Retrieve chunks, claims, outputs, and graph neighborhoods before generation.
Review Stage outputs, cite evidence, capture decisions, and export to working systems.

The Platform Move

HAL keeps the research OS. The agent runtime supplies the nervous system.

The rebuild is a deliberate graft. Research programs, provenance, canonical storage, graph memory, review, exports, and governance remain HAL-owned. The ml-intern-inspired runtime adds sessions, model routing, context compaction, tool approvals, and cloud compute adapters.

Research contract

Programs declare objective, scope, budgets, tools, and required outputs before execution begins.

Agent execution

Sessions stream events, call approved tools, compact context, and record every meaningful operation.

Reviewable memory

Generated work is staged against sources, claims, graph edges, output versions, and review decisions.

This is the central architectural point. HAL should feel modern because the agent experience is live, but the important difference is that the live layer cannot escape the ledger.

The important phrase is "same records." HAL's non-CLI interfaces are not separate products. They are different views over the research ledger.

Agent Nervous System

Interactive agents with durable boundaries.

The graft gives HAL a modern session experience while preserving run accounting and human control.

Model adapter

LiteLLM-style routing resolves model config and retries transient provider failures across OpenAI, Anthropic, Hugging Face, and local endpoints.

Tool approvals

Gated operations pause active turns until policy or a human decision authorizes the tool call.

Context compaction

Long sessions preserve the system prompt, first task, recent context, and provider-valid tool pairs.

Event replay

Gateway sessions can recover from durable run events instead of relying only on live memory.

HAL tools

Acquisition, PDFs, memory search, staged outputs, exports, ADAM context, reviews, and graph edges are exposed through approved service adapters.

HF compute

Jobs, scheduled jobs, repo operations, artifact harvests, and sandbox actions attach outputs and events to HAL runs.

Budget records

Tool calls, runtime limits, LLM calls, and warnings are captured as operational telemetry.

Interruptibility

Sessions can compact, interrupt, approve, replay, and inspect history through the gateway API.

This is where the ml-intern inspiration shows up. HAL is adopting the mechanics, not handing over product ownership.

Operational Control

State-of-the-art research systems need brakes, not just acceleration.

HAL's rebuilt platform includes governance primitives that make powerful agent behavior easier to inspect, contain, and release responsibly.

Permissions

Users, teams, roles, project grants, and SSO/OIDC planning sit behind review and gateway actions.

Retention

Policies cover operational rows, PDFs, artifacts, logs, generated outputs, and legal-hold safeguards.

Secrets

Provider secret-manager abstraction keeps model APIs, Slack, Sheets, and HF credentials out of ordinary config paths.

Copyright checks

PDF handling and generated summaries can be screened before artifacts move through the system.

CI and release

Ruff, type checks, MkDocs strict build, package build, pytest, changelog automation, and service packaging.

Observability

Run metrics, queue metrics, tool calls, costs, errors, latency, acquisition outcomes, and worker status.

Artifacts

Local and S3-compatible object storage keep PDFs, generated outputs, HF job results, and manifests durable.

Replay

Durable gateway events let session history recover across runtime restarts.

For technical and commercial audiences, the serious differentiator is not that HAL can use agents. It is that HAL can make agent use governable.
